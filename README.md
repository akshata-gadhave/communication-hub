# Communication Hub

## Project Overview
Communication Hub is a REST API application developed using Java and Spring Boot. It manages communication messages through different channels such as SMS and Email.

## Technologies Used
- Java 21
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven
- JUnit and MockMvc

## Features
- Create a communication message
- Retrieve all messages
- Retrieve a message by ID
- Search messages by channel
- Search messages by state
- Update an existing message
- Delete a message
- Pagination support
- Request validation and exception handling

## API Base URL
`/v1/communicationMessage`

## Testing
The project includes unit tests for the service layer and controller layer.
